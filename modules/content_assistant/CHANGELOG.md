# Changelog

## 1.0.0 - 2026-11-25

- Four Tool API tools: list collections, search (newest first), count by group
  or year, and create unpublished drafts.
- Settings page to choose content types, date, group and searchable fields.
- MCP mappings for MCP Server Tool Bridge, installed with the bridge.
- Kernel tests for the tools, permissions, the settings form and MCP exposure.
